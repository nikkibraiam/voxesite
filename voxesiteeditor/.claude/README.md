# .claude — Slash Commands & Agent Prompts

## Commands (invoke with `/project:name`)

| Command | Model | Description |
|---|---|---|
| `/project:fix-bugs` | Sonnet | Fix all 5 active bugs. Reads contracts first, then implements each fix in order. |
| `/project:generate-agent-examples` | Sonnet | Generate sneaker store + courses page JSON examples and inject into agent prompt file. Run once after initial setup. |
| `/project:status` | **Haiku** | Fast read-only check — shows bug status, agent status, and placeholder status. Low cost. |

## Prompts (loaded by agents at runtime, not invoked directly)

| File | Used by |
|---|---|
| `prompts/site-clone-agent.xml` | `VoxeSiteCloneAgent` — clones a site from URL into PageBlock[] |
| `prompts/site-builder-agent.xml` | `VoxeSiteBuilderAgent` — generates a site from natural language description |

## Placeholders in prompt files

Both XML files have `{{PLACEHOLDERS}}` that must be injected at runtime by the agent service:

| Placeholder | Source |
|---|---|
| `{{BLOCK_REGISTRY}}` | `packages/contracts/blocks.ts` — injected at composable init |
| `{{PAGE_BLOCK_SCHEMA}}` | `packages/contracts/types.ts` — injected at composable init |
| `{{SNEAKER_STORE_EXAMPLE}}` | Generated by `/project:generate-agent-examples` — injected once |
| `{{COURSES_PAGE_EXAMPLE}}` | Generated by `/project:generate-agent-examples` — injected once |

## Recommended first-run order

```
1. /project:status                   # check what's already done
2. /project:fix-bugs                 # implement all 5 bug fixes
3. /project:generate-agent-examples  # fill in the reference site JSONs
4. /project:status                   # confirm everything is green
```

## Token optimization tips

- Use `/project:status` (Haiku) before any session to orient without burning Sonnet tokens.
- The `fix-bugs` command is designed to batch all 5 fixes in one session — don't split it.
- Agent XML prompts use `{{BLOCK_REGISTRY}}` injection so the registry is never duplicated in code.
